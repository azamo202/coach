# CoachMint

تطبيق جوال (iOS + Android) مبني بـ Flutter. المستخدم يختار **أي رياضة** ويحدد
**مستواه** (مبتدئ / متوسط / محترف)، والذكاء الاصطناعي يبني له برنامجاً تدريبياً
**متدرجاً أسبوعياً** خاصاً به — مع عدد المجموعات والتكرارات وطريقة أداء كل تمرين.

هذا التطبيق هو التطوير الكامل للنموذج الأولي `ai-sports-coach-prototype`.

---

## ما الذي يقدّمه التطبيق

| الميزة | الوصف |
|---|---|
| **اختيار حر للرياضة** | اكتب أي رياضة — لا قوائم مغلقة. مع 18 اقتراحاً سريعاً |
| **ثلاثة مستويات** | مبتدئ / متوسط / محترف — لكل مستوى شدة وحجم ومدة برنامج مختلفة |
| **برنامج متدرج** | كل أسبوع أصعب من الذي قبله، مع بيان التدرّج في حقل مستقل |
| **تفاصيل كاملة لكل تمرين** | مجموعات، تكرارات، راحة، إيقاع، عضلات مستهدفة، أدوات |
| **مرجع طريقة الأداء** | شرح خطوة بخطوة لكل تمرين + روابط فيديو وصور |
| **تتبّع تلقائي** | نسبة الإنجاز، الجلسات المكتملة، السلسلة اليومية، رسم بياني أسبوعي |
| **رياضات متعددة** | حفظ حتى 12 رياضة بالتوازي، لكل واحدة تقدّمها المستقل |
| **حسابات كاملة** | تسجيل، دخول، استعادة كلمة مرور، تعديل بيانات، حذف حساب |
| **بيانات الصحة** | Apple HealthKit على iOS و Health Connect على Android |
| **عربي بالكامل** | RTL، خط Cairo، كل النصوص عربية |

## التشغيل السريع

### 1. تجهيز المشروع

المشروع يحتوي على كود Dart كاملاً. سكربت `setup` يولّد مجلدات `android` و `ios`
الأصلية ويطبّق عليها إعدادات التطبيق (اسم عربي، صلاحيات الصحة، minSdk).

**Windows:**
```bash
cd coachmint && powershell -ExecutionPolicy Bypass -File setup.ps1
```

**macOS / Linux:**
```bash
cd coachmint && bash setup.sh
```

### 2. تشغيل الباك إند

```bash
cd coachmint/backend && cp .env.example .env && npm install && npm start
```

ثم ضع مفتاح Anthropic في `backend/.env`.

### 3. تشغيل التطبيق

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080
```

> `10.0.2.2` هو عنوان جهازك من داخل محاكي أندرويد. على محاكي iOS استخدم
> `http://localhost:8080`، وعلى جهاز حقيقي استخدم عنوان IP لجهازك على الشبكة.

## وضعان للتشغيل

التطبيق يعمل بوضعين حسب وجود `API_BASE_URL`:

### وضع الإنتاج (موصى به)
```bash
flutter run --dart-define=API_BASE_URL=https://api.coachmint.app
```
- الحسابات على السيرفر (bcrypt + JWT)
- البرامج تُحفظ في قاعدة البيانات وتُزامَن على الأجهزة
- **مفتاح Anthropic يبقى على السيرفر** — لا يُشحن مع التطبيق أبداً
- التطبيق يعمل بدون إنترنت من الذاكرة المحلية ويزامن عند عودة الاتصال

### وضع العرض المحلي
```bash
flutter run --dart-define=ANTHROPIC_API_KEY=sk-ant-...
```
- كل شيء على الجهاز، بدون سيرفر — مفيد للتجربة والعرض على العميل
- **لا تنشر بهذا الوضع أبداً**: المفتاح يكون داخل حزمة التطبيق ويمكن استخراجه

## كيف يضمن التطبيق اختلاف البرامج حسب المستوى

كل مستوى يحمل توصيفاً تدريبياً يُحقن في الـ prompt:

| | مبتدئ | متوسط | محترف |
|---|---|---|---|
| مدة البرنامج | 4 أسابيع | 6 أسابيع | 8 أسابيع |
| جلسات/أسبوع | 3 | 4 | 5 |
| الشدة | 50-65% | 65-80% | 80-95% |
| الراحة | 60-90 ث | 45-90 ث | حسب التقسيم الدوري |
| نوع التمارين | حركة أساسية، وزن الجسم | مركّبة + مهارات نوعية | تقسيم دوري، بليومترك، تباين |

انظر `lib/data/models/fitness_level.dart` (`coachingBrief`) و
`lib/data/services/prompt_builder.dart`.
