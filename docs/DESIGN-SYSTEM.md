# نظام التصميم

الهوية البصرية (الألوان والخطوط والشعار) في [`BRAND.md`](BRAND.md).
هذا الملف يشرح **كيف تُبنى الشاشات** فوق تلك الهوية.

القاعدة الحاكمة: **الشاشة لا تخترع شيئاً.** كل قياس من `Space` أو `Radii`،
وكل نمط نصّي من `AppType`، وكل عنصر من مكتبة `core/widgets`. إن احتاجت شاشة
شيئاً غير موجود، يُضاف إلى النظام لا إلى الشاشة.

## المسافات

سلّم واحد بمضاعفات الأربعة. لا قيمة خارجه.

```
xxs 2 · xs 4 · sm 8 · md 12 · lg 16 · xl 20 · xxl 24 · x3 32 · x4 40 · x5 48 · x6 64
```

| ثابت | القيمة | أين |
|---|---|---|
| `Space.screenInset` | 20 | الهامش الأفقي لكل شاشة — **بلا استثناء** |
| `Space.lg` | 16 | الحشو الافتراضي للبطاقات |
| `Space.md` | 12 | بين عناصر القائمة |
| `Space.xxl` | 24 | بين مجموعتين داخل قسم |
| `Space.x3` | 32 | بين قسمين |
| `Space.bottomBarClearance` | 112 | أسفل الشاشات ذات الشريط العائم |

## الاستدارات

| ثابت | القيمة | أين |
|---|---|---|
| `Radii.xs` | 8 | الشارات الصغيرة، أرقام التمارين |
| `Radii.sm` | 12 | الحقول الداخلية، مربّعات الأيقونات |
| `Radii.md` | 16 | الحقول، الأزرار، البطاقات الداخلية |
| `Radii.lg` | 20 | البطاقات الرئيسية، حوارات التأكيد |
| `Radii.xl` | 28 | الأوراق السفلية |
| `Radii.pill` | ∞ | الشرائح والشارات |

## الأيقونات

عائلة واحدة: Material Symbols بلاحقة `_rounded`. ثلاثة مقاسات:
`IconSizes.sm 16` · `md 20` · `lg 24` (و`xl 28` للحالات الفارغة).

أيقونات الاتجاه تُكتب باتجاهها **المنطقي** (`chevron_right` = للأمام) ويعكسها
الإطار تلقائياً في الواجهة العربية.

## الحركة

| ثابت | المدّة | متى |
|---|---|---|
| `Motion.fast` | 150ms | تغيّر حالة في مكانه: ضغط، تحديد |
| `Motion.base` | 220ms | فتح قسم، ظهور عنصر |
| `Motion.slow` | 320ms | الانتقال بين الشاشات |
| `Motion.progress` | 560ms | تعبئة أشرطة التقدّم — أبطأ عمداً لتُقرأ الزيادة |

## المكوّنات

| المكوّن | يستبدل |
|---|---|
| `AppButton` (`.primary` · `.secondary` · `.ghost` · `.danger`) | كل زرّ في التطبيق |
| `AppIconButton` | زرّ الأيقونة — `tooltip` إلزامي |
| `AppTextField` | كل حقل: عنوان ظاهر، نص مساعد، تحقّق عند الخروج |
| `AppCard` | السطح الوحيد |
| `ScreenHeader` | رأس كل شاشة — نفس الموضع والمقاس والمسافة تحته |
| `SectionHeader` | عنوان قسم داخل الشاشة |
| `AppChip` | خيار قابل للضغط |
| `AppTag` | شارة ثابتة لا تُضغط |
| `AppMetricPill` | قيمة + وحدة |
| `SportMark` · `AppAvatar` | شارات الأحرف |
| `ProgressBar` · `ProgressRing` | كل مؤشّرات التقدّم |
| `StatTile` · `StatRow` | صفّ الإحصاءات |
| `EmptyState` · `ErrorStateView` · `AppNotice` | الحالات الفارغة والأخطاء |
| `Skeleton` · `SkeletonList` | التحميل |
| `showConfirmDialog` · `showAppSnack` | التأكيد والرسائل السريعة |

### قواعد المكوّنات

- **زرّ أساسي واحد لكل شاشة.** ما عداه ثانوي أو صامت.
- **البطاقة ليست الحلّ الافتراضي.** استخدمها حين يكون المحتوى وحدة قائمة
  بذاتها، لا لمجرد تأطير نص.
- **`AppChip` يُضغط و`AppTag` لا يُضغط.** ما لا يُضغط لا يجوز أن يبدو
  قابلاً للضغط.
- **اللون يحمل معنى أو لا يوجد.** الأرقام في `StatTile` محايدة؛ المرجاني
  للسلسلة اليومية وحدها.

## الحالات

كل شاشة تعرض بيانات تغطّي أربع حالات، لا الحالة المثالية وحدها:

| الحالة | الشكل |
|---|---|
| تحميل | `Skeleton` بشكل المحتوى النهائي ومقاسه — لا دوّارة في فراغ |
| فارغة | سبب مكتوب + إجراء واحد يخرج المستخدم منها |
| خطأ | ما الذي حدث + زرّ «حاول مرة ثانية» |
| نجاح | تأكيد قصير في `SnackBar`، بلا احتفال |

## إمكانية الوصول

- درجات النص الثلاث ≥ 4.5:1 فوق كل سطح — يحرسها اختبار.
- تدرّجات الأزرار ≥ 4.5:1 لنص Spruce عند طرفيها — يحرسها اختبار.
- كل هدف لمس ≥ 48dp، وكل زرّ أيقونة له `tooltip`.
- الحالة تُنقل بأكثر من اللون: الشريحة المحدّدة تغيّر لونها **و** سُمك حدّها
  **و** وزن نصّها؛ التبويب النشط يبدّل الأيقونة من مفرّغة إلى ممتلئة.
- الأيقونات المكرّرة لنصّها مخفيّة عن القارئ الصوتي (`ExcludeSemantics`)،
  والرسم البياني يرفق ملخّصاً نصّياً.
- `Skeleton` يتوقّف عن النبض عند تفعيل «تقليل الحركة».
- كل إجراء بالسحب له بديل بالضغط (حذف البرنامج متاح من قائمة «⋯»).
